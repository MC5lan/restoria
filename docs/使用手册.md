# Restoria · 使用手册

写给：日常使用本工具归档档案的操作人员。不需要任何电脑专业知识，照着步骤点就行。

---

## 一、这个软件是干什么的

把扫描好的老档案图片，一键变成**标准 A4、白底黑字、方向端正、干净无污**的归档件。原来手工要做的事情（转方向、裁边、去污、去黑点、排 A4 版面），现在点一次按钮全部自动完成。

## 二、快速上手：归档一卷档案（三步）

**第 1 步：打开档案所在的文件夹**

启动软件后，左侧是文件夹列表。找到扫描件存放的文件夹，点开它，中间会显示这一夹的图片缩略图。

**第 2 步：点「归档本文件夹（全部）」**

在「归档」页的右侧栏里找到这个按钮（带魔棒图标），点它。软件会弹一个确认框，告诉你涉及多少个文件夹、多少张图——确认无误后点「开始归档」。

- 归档过程中进度条会走动，想中途停下就点「取消归档」
- 如果文件夹里还有子文件夹，**子文件夹里的图也会一并归档**（各归各的，不会混）

**第 3 步：取成品**

归档完成后软件自动跳到成品位置。每张原图所在文件夹里会新建一个 **「已归档」** 文件夹，处理好的 A4 成品都在里面。**原图永远不动**，放心。

归档完成后会弹出提示条告诉你成功多少张、耗时多久。

## 三、归档档位怎么选

右侧栏顶部有两个选项：

| 档位 | 适合 | 特点 |
|------|------|------|
| **普通归档** | 大多数档案 | 速度与干净度平衡；方向只认装订孔证据 |
| **极致归档** | 字迹淡、内容重要的档案 | 只删最确定的尘点，删过头自动撤销；无装订孔的页用 OCR 判断方向。慢一些，字更不容易掉 |

选好的档位会被**记住**，下次打开软件还是你上次选的。

一句话建议：先跑普通档抽查几页，发现小黑点影响阅读、或者担心手写字被误删，再换极致档重跑。

## 四、归档报告怎么看

每次整卷归档完成后，输出文件夹里会生成 **「归档报告.txt」**，用记事本打开就能看。每一行是一页的"处理记录"：

- 原图尺寸 → A4 成品尺寸
- 方向转了几度、靠什么判断的（装订孔 / OCR）
- 清了几个黑点、有没有触发"撤销保险"
- 这一页花了多久

哪一页有问题，照着报告里的文件名找原图核对就行。如果有归档失败的页，同目录还会有一份「归档日志.txt」写明失败原因。

## 五、中断了怎么办

- **点了取消**：已经归档的页不受影响。下次再对同一个文件夹跑归档，**只会补做没归档的页**（已完成的自动跳过），不用从头再来。
- **电脑断电/死机**：同上，重新跑一遍即可。
- **改了原图想重新归档**：把对应文件夹里的「已归档」文件夹删掉（或改名），再跑一次归档。

## 六、其他常用功能

软件顶部按功能分了 9 个页签，也可以按 **Ctrl+1 ~ Ctrl+9** 快速切换：

| 页签 | 干什么用 |
|------|----------|
| 去除 | 抹掉污渍、印章残留（笔刷/框选涂抹，五种修复模式） |
| 裁剪 | 手动裁掉不要的部分 |
| 方向 | 手动旋转、一键自动纠偏 |
| 调色 | 亮度/对比度/饱和度/色温、色阶、Gamma、锐化（数值可点击直接输入） |
| 印章 | 给褪色的红章补色 |
| 文字 | 往图上加文字标注 |
| 扫描 | 直接连接扫描仪扫图（输出格式可选 JPG/PNG/TIF） |
| 文件 | 批量重命名、文件夹管理 |
| 归档 | 一键归档入口（普通/极致两档） |

顶栏的太阳/月亮图标切换浅色和深色界面，选择会被记住。

## 七、常见问题

**Q：点了归档，提示"该路径不允许归档"？**
为了防止误操作，桌面、C 盘根目录、Windows 系统文件夹、用户主目录这些位置**不允许**整树归档。把档案复制到一个普通文件夹（比如 D:\档案\2024年\）再操作。

**Q：成品图片方向不对/有瑕疵，原图还在吗？**
在。归档全程只新增文件，原图一个字节都不会动。找到原图所在文件夹即可。

**Q：某一页的字被删掉了一点 / 黑点没删干净？**
换「极致归档」重跑这一卷。极致档宁可留黑点也不吃字，并带"删过头自动撤销"的保险。

**Q：AI 修复不可用？**
AI 是可选功能，需要 exe 同级的 `ai\` 目录备齐运行时与模型。用 `--ai-check` 可以查原因（报告落 %TEMP%\PicTool-ai-check.txt）。AI 不可用不影响其他任何功能。

**Q：能归档手机拍的照片吗？**
本工具针对**扫描仪输出的平面扫描件**设计。手机拍照有透视变形，不保证效果，请尽量用扫描件。
